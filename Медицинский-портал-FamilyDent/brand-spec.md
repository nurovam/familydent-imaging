# FamilyDent — визуальная система портала

Источник: https://familydent.netlify.app/ ; извлечено из опубликованных CSS и HTML 01.11.2026.

## Токены источника
- `--bg: oklch(97.8% .006 85)` — paper-2
- `--surface: oklch(100% 0 0)` — surface
- `--fg: oklch(23% 0 0)` — ink
- `--muted: oklch(49% .012 85)` — muted
- `--border: oklch(89% .009 85)` — rule
- `--accent: oklch(78% .055 82)` — accent, мягкий золотистый
- `--trust: oklch(36% .047 174)` — дополнительный семантический цвет доверия
- Успех: oklch(53% .13 160); ошибка: oklch(58% .18 25).

## Типографика
- Заголовки: "Roboto Serif", Georgia, serif — фактический шрифт текущего сайта.
- Текст: "Golos Text", -apple-system, system-ui, sans-serif.
- Технические идентификаторы: ui-monospace, Menlo, monospace (системный резерв вместо третьего загружаемого шрифта).

## Характер интерфейса
1. Графитовая навигация и белые рабочие поверхности; тонкие разделители.
2. Скругления источника: 8, 12, 18, 28 px; кнопки pill; минимальная высота портала 44 px.
3. Золотистый акцент дозирован: активная навигация и основное действие.
4. Шаг отступов 8 px; крупные заголовки с отрицательным трекингом.
5. В портале маркетинговая воздушность адаптирована под таблицы; тёмный холст просмотрщика отделён от остального интерфейса.

## Границы прототипа
Все пациенты, врачи, события и исследования вымышлены. Вход, отправка писем, временные ссылки и загрузка моделируются локально. Серверной авторизации и DICOM-декодирования нет. Просмотрщик показывает синтетическое схематическое изображение, не пригодное для диагностики; скачивание реальных DICOM/Romexis недоступно без подключённого архива.
